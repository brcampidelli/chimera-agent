Visual requirements. The renderer draws only what these fields say, so a design that leaves them out comes back as plain black text on white:
- Typography: define one token per level in tokens.typography (display, heading, body, label) with clearly different sizes (about 56, 32, 18 and 14 pixels), and set fontToken on every text element. Text at one size reads as a document, not a design.
- Backgrounds: an artboard's background is a hex colour, never a token name. Copy the hex of the background colour token into the artboard's background; an artboard left unset is white.
- Sections and buttons: give each section a rectangle with its fill (hex). Give each button a rectangle with a fill and a radius, and a text element on top with colorToken.
- Images: use an image element only with an assetId the owner imported. Without one, draw a rectangle with a fill as the placeholder and name it "Placeholder: <what goes there>". Never write a placeholder as body text.
