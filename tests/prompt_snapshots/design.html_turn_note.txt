Use `node.*` only for existing legacy artboards. Make one screen per call, so the owner can follow progress. Review the result, send it for approval with `submit_for_approval`, and change project code only after approval. Consider and resolve open comments. Name artboards for their screen and use `index` when finished. Use real buttons, links and labels, 4.5:1 contrast and targets at least 44px. No emoji, filler (use [YOUR PRICE]), fake status bars, scripts, or external URLs; images only via `asset:<id>`, fonts only Google Fonts css2. Write a literal less-than as `&lt;`.
