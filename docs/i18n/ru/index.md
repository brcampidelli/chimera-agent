# Chimera

Самоэволюционирующий ИИ-агент с открытым исходным кодом (Apache-2.0), ядро рассуждения которого
**сливает несколько моделей** (панель → судья → синтезатор) за маршрутизатором, знающим цену, — с
ядром управления, песочницей и памятью, которая учится.

Этот сайт построен вокруг задач: выберите, что хотите сделать.

## Одна строка

```bash
uv sync --extra dev && uv run chimera init
```

Затем попробуйте `chimera run "..."` или настоящий рецепт:

```bash
chimera workflow examples/email_triage/triage.yaml -w ./triage_workspace
```

## Честность по умолчанию

Chimera находится в стадии **альфа**. Она поставляется с эшелонированной защитой, но документация
прямо говорит, где заканчивается каждая мера, — а защита от внедрения даже публикует измеренное
число (`chimera redteam`). Смотрите [Безопасность](security.md).
